## 1. 동적 계획법(DP)이란?

- 복잡한 문제를 여러 개의 `작은 하위 문제(subproblems)`로 나누어 푸는 문제 해결 패러다임
- 각 하위 문제의 해결책을 한 번만 계산하고, 그 결과를 `메모이제이션(Memoization)` 또는 `타뷸레이션(Tabulation)`을 통해 저장
- 동일한 하위 문제의 반복 계산을 피하여 알고리즘의 효율성을 크게 향상시킴

## 2. DP의 조건

- DP를 적용하려면 문제가 다음 두 가지 속성을 만족해야 함

### 1. 최적 부분 구조 (Optimal Substructure)
- 문제의 최적 해결책이 그 하위 문제들의 최적 해결책으로 구성될 수 있는 구조
- 예: 최단 경로 문제에서 A에서 C로 가는 최단 경로는, 중간 지점 B를 거친다면 A-B 최단 경로와 B-C 최단 경로의 합으로 구성됨

### 2. 중복되는 하위 문제 (Overlapping Subproblems)
- 재귀적인 해결 과정에서 동일한 하위 문제가 여러 번 반복적으로 나타나는 구조
- DP는 이 중복 계산을 피하기 위해 한 번 계산된 결과를 저장함

## 3. 접근 방법

### 메모이제이션 (Memoization) - Top-down 방식
- 재귀 호출을 기반으로 문제를 큰 것부터 작은 것으로 해결
- 계산한 하위 문제의 결과를 배열이나 해시 테이블에 저장하고, 필요할 때 꺼내 씀 (캐싱)
- 아직 해결되지 않은 문제에 대해서만 계산을 수행

### 타뷸레이션 (Tabulation) - Bottom-up 방식
- 반복문을 기반으로 문제를 가장 작은 하위 문제부터 점차적으로 해결
- 보통 1차원 또는 2차원 배열인 `DP 테이블`을 만들어 결과를 순차적으로 채워나감
- 재귀 호출이 없어 오버헤드가 적을 수 있음

## 4. 예시: 피보나치 수열

- `f(n) = f(n-1) + f(n-2)`는 대표적인 DP 문제

### 타뷸레이션 (Bottom-up) 방식 구현

```python
def fib_dp(n):
    # DP 테이블(결과 저장용 리스트) 초기화
    if n == 0:
        return 0
    
    dp = [0] * (n + 1)
    dp[1] = 1
    
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
        
    return dp[n]

# n=10일 때 피보나치 수
result = fib_dp(10) # 결과: 55
```
