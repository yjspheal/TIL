# **공부 원칙**

## **1. 하루에 새로운 내용은 하나의 메인 과목만**

메인 과목을 공부한 뒤 시간이 남으면 프로그래밍이나 SQL 문제를 추가한다.

## **2. 일요일은 새로운 진도를 나가지 않음**

```text
지난 내용 복습
+
오답 정리
+
밀린 공부 보충
```

## **3. SQL과 프로그래밍은 계속 유지**

SQL을 핵심 문법까지 공부한 후에는 완전히 손을 놓지 않고, DB 공부 이후에도 주 2~3회 짧은 문제를 푼다.

C / Java / Python도 새로운 개념을 끝낸 후 기출 문제를 계속 반복한다.

## **4. 10월부터는 기출 비중 증가**

```text
9월
→ 개념 이해 + 1회독

10월 초
→ 개념 마무리 + 기출 시작

10월 중순 이후
→ 기출 + 오답 + 반복

시험 직전
→ 암기 + 실전 답안 작성
```
