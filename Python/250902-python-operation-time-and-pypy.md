## Python의 연산 속도

- 일반적으로 **CPython 기준 1초에 약 3천만 번**의 연산이 가능하다고 알려짐 (물론 연산의 종류나 시스템 환경에 따라 다를 수 있음)
- 이 수치는 알고리즘 문제 풀이에서 시간 복잡도를 어림짐작하는 데 유용한 기준이 됨

---

## 시간 복잡도와 연산 횟수 계산 예시

- **상황**: 59개의 테스트 케이스(TC)를 합쳐 3초의 시간 제한이 주어진 경우
- **계산**:
    1.  총 연산 가능 횟수: `3초 * 30,000,000번/초 = 90,000,000번`
    2.  테스트 케이스 1개당 허용 연산 횟수: `90,000,000번 / 59개 ≈ 1,525,423번` (약 150만 번)
- **전략**:
    - 이를 통해 문제의 시간 제한과 데이터 크기를 보고, 허용되는 시간 복잡도의 상한선을 대략적으로 예측하는 전략을 세울 수 있음
    - 예를 들어, N=1,000,000일 때 O(N log N)은 시간 초과될 수 있지만, O(N)은 통과 가능성이 높다고 판단하는 식

## PyPy vs Python 3

알고리즘 문제 풀이 사이트에서 자주 볼 수 있는 두 인터프리터는 각각 장단점이 뚜렷함

### Python 3 (CPython)
- 우리가 흔히 '파이썬'이라고 부르는 **표준 인터프리터**
- **장점**:
    - 메모리를 비교적 효율적으로 사용
    - 모든 파이썬 라이브러리와의 호환성이 뛰어남
- **단점**:
    - 인터프리터 방식이라 실행 속도가 PyPy보다 느림

### PyPy
- **JIT(Just-In-Time) 컴파일** 방식을 사용하는 파이썬 구현체
- **장점**:
    - 코드를 실행하는 시점에 기계어로 컴파일하여, 특히 **반복문이 많은 연산**에서 CPython보다 훨씬 빠른 속도를 보임
- **단점**:
    - CPython보다 메모리 사용량이 더 많은 경향이 있음
    - 일부 C 확장 라이브러리(예: Numpy)와의 호환성 문제가 발생할 수 있음 (최근에는 많이 개선됨)

### 비교 요약

| 구분 | PyPy | Python 3 (CPython) |
| :--- | :--- | :--- |
| **장점** | **실행 속도 빠름** (특히 반복문) | **메모리 효율성**, 높은 호환성 |
| **단점** | 메모리 사용량 더 많음, 일부 호환성 문제 | 상대적으로 느린 실행 속도 |

## 정리
- **시간 복잡도 예측**: "1초 ≈ 3천만 번 연산"을 기준으로 문제의 요구사항에 맞는 알고리즘을 선택하는 것이 중요함
- **인터프리터 선택**:
    - 단순 연산, 반복문이 많은 DP, 시뮬레이션 등의 문제에서는 **PyPy**가 유리함
    - 메모리 제한이 엄격하거나, 특정 라이브러리 사용이 필수적인 경우에는 **Python 3**가 안정적일 수 있음
