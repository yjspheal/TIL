## 데코레이터란 무엇인가?

### 내용

**데코레이터(decorator)** 란,
- 함수(또는 클래스)에 새로운 기능을 "간편하게" 추가할 수 있는 문법적 도구  
- 함수를 인자로 받아서, 새로운 함수(또는 클래스)를 반환하는 함수
- `@` 기호로 사용

<br><br>

### 예시

```python
def my_decorator(func):
    def wrapper():
        print("함수 실행 전!")
        func()
        print("함수 실행 후!")
    return wrapper

@my_decorator
def hello():
    print("안녕, SSAFY!")

hello()
# 출력
# 함수 실행 전!
# 안녕, SSAFY!
# 함수 실행 후!
```
<br><br>
### 주요 포인트

- 데코레이터는 원본 함수의 동작을 감싸서(before/after 등) 부가기능을 넣을 때 자주 사용  
- 대표적으로 로그 출력, 실행 시간 측정, 권한 체크 등에 활용됨
- 여러 데코레이터를 겹쳐서 사용할 수도 있음

<br><br>
### 추가 학습

- 파라미터가 있는 함수/메서드 데코레이팅
- functools.wraps를 사용해 원본 함수의 정보를 유지하는 법
- 파이썬 내장 데코레이터 예시
  - `@staticmethod`, `@classmethod`, `@property` 등
