# 총평
- 구현 로직이 명확하며 가독성이 좋습니다.  
- 내장 함수를 활용해 16진수 → 2진수 변환을 간결히 처리했습니다.

<br>

# 보완점
## 1. 헥사→이진 변환 로직 단순화
- `int(ch, 16)`과 `format(..., '04b')`를 활용하면 직접 몫/나머지 연산 없이 4비트 문자열을 얻을 수 있습니다.  
- 예시:
    ```python
    def hex_to_bin(ch):
        return format(int(ch, 16), '04b')
    ```

## 2. 오류 처리 및 매직 넘버 제거
- `int(ch, 16)` 하나로 0~9, A~F 모두 처리되므로 별도의 `dict`나 `try/except`가 불필요합니다.  
- 하드코딩된 8, 4, 2, 1 같은 매직 넘버 연산은 모두 제거됩니다.

## 3. 함수명·변수명 가독성
- `hexa_to_bi` → `hex_to_bin`  
- `hexa_str` → `hex_str`, `bi_str` → `bin_str`  
- 사용하지 않는 입력은 언더바(`_`)로 받아 명시적으로 처리하세요.

<br>

# 최종 코드 예시
```python
T = int(input())
for tc in range(1, T + 1):
    _, hex_str = input().split()
    bin_str = ''.join(format(int(ch, 16), '04b') for ch in hex_str.upper())
    print(f'#{tc} {bin_str}')
```
