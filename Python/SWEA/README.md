# 알고리즘 문제 풀이 기록

> 알고리즘 문제를 풀이한 코드와, AI 피드백을 통해 개선한 과정을 정리한 저장소입니다.  
> 문제를 풀고 개선하는 과정을 반복하며, 실력 향상을 목표로 합니다.

## 폴더 구조 및 파일 규칙

- 각 문제는 **`YYYYMMDD_난이도_문제번호`** 형식의 폴더에 저장됩니다.
- 폴더 내부에는 다음 두 파일이 포함됩니다:

| 파일명 예시                         | 설명                                      |
|------------------------------------|-------------------------------------------|
| `250722_D2_5186.py`                | 알고리즘 문제 풀이 코드                   |
| `250722_D2_5186_feedback.md`       | 해당 코드에 대한 AI 피드백 및 개선 기록   |


## 목적

- 문제 해결 능력 향상 및 풀이 습관화
- AI 피드백을 통해 코드 품질 개선 및 리팩토링 습관 강화
- 마크다운 기반의 기록을 통해 복습과 관리 용이성 확보

---

> 새로운 문제를 풀 때마다 폴더를 추가하고, 이 구조를 반복해 나갑니다.
