# 얕은 복사(shallow copy)와 깊은 복사(deep copy)
## 변수 간 대입
### mutable한 객체의 변수 간 대입
- b 에 a를 할당하면 값이 할당되는 것이 아니라 같은 메모리 주소를 바라봄
- 따라서 b를 변경하면 같이 a도 바뀜

- list의 얕은 복사 예시
```python
a = [1, 2, 3]
b = a        # shallow copy
b[0]= 5

a            # [5, 2, 3]
b            # [5, 2, 3]

id(a)        # 4396179528
id(b)        # 4396179528
```

### immutable한 객체의 변수 간 대입
- b 에 a를 할당하면 값이 할당되는 것이 아니라 같은 메모리 주소를 바라봄 <- **은 동일**
- 하지만 b에 다른 값을 할당하면 '재할당'이 이루어져 메모리 주소 변경
- 따라서 a와 b는 다른 값을 가짐

- list의 얕은 복사 예시
```python
a = 'abc'
b = a

a            # 'abc'
b            # 'abc'

id(a)        # 4387454680
id(b)        # 4387454680

b = 'abcd'

a            # 'abc'
b            # 'abcd'

id(a)        # 4387454680
id(b)        # 4396456400
```

## 얕은 복사
- mutable한 객체 안에 mutable한 객체가 있는 경우, 얕은 복사는 바깥 객체만 복사하고 내부 객체는 참조(공유)만 함

- 따라서 **내부 객체를 변경하면 원본 객체도 영향**을 받음
- 예시:
```python
import copy

a = [[1, 2], [3, 4]]
b = copy.copy(a)   # 얕은 복사

b[0][0] = 100

print(a)           # [[100, 2], [3, 4]]  ← 내부 리스트가 같이 바뀜
print(b)           # [[100, 2], [3, 4]]
print(id(a) == id(b))          # False   ← 겉 리스트는 다른 객체
print(id(a[0]) == id(b[0]))    # True    ← 내부 리스트는 같은 객체
```

## 깊은 복사
- 객체 전체를 재귀적으로 복사함
- 즉, 바깥 객체뿐 아니라 내부에 포함된 모든 객체도 새로운 복사본으로 생성
- 따라서 복사본을 수정해도 원본에는 영향을 미치지 않음
- 예시:
```python
import copy

a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)   # 깊은 복사

b[0][0] = 100

print(a)           # [[1, 2], [3, 4]]     ← 원본 그대로 유지
print(b)           # [[100, 2], [3, 4]]
print(id(a) == id(b))          # False
print(id(a[0]) == id(b[0]))    # False    ← 내부 리스트도 다른 객체
```

## 정리

| 구분         | 변수 간 대입        | 얕은 복사 (`copy.copy`) | 깊은 복사 (`copy.deepcopy`) |
|--------------|---------------------|--------------------------|-----------------------------|
| 겉 객체 복사 | X (같은 객체 공유)  | O (새 객체 생성)        | O (새 객체 생성)           |
| 내부 객체 복사 | X (공유)           | X (공유)                 | O (완전 복사)              |
| 독립성       | 없음                | 부분적                  | 완전한 독립                |
