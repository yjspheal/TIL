# **정보처리기사 실기 — 복습**

## **SQL 복습**

오늘은 지금까지 배운 SQL 문법을 복습했다.

### **GROUP BY + HAVING**

```sql
SELECT dept, COUNT(*)
FROM student
WHERE age >= 20
GROUP BY dept
HAVING COUNT(*) >= 2
ORDER BY COUNT(*) DESC;
```

실행 흐름:

```text
WHERE
→ 20세 이상인 학생만 조회

GROUP BY
→ 학과별로 그룹화

COUNT
→ 학과별 학생 수 계산

HAVING
→ 학생 수가 2명 이상인 그룹만 조회

ORDER BY
→ 학생 수가 많은 순으로 정렬
```

### **JOIN 복습**

여러 테이블의 데이터를 함께 조회할 때 `JOIN`을 사용한다.

```sql
SELECT department.dept_name, COUNT(student.id)
FROM department
JOIN student
ON department.dept_id = student.dept_id
WHERE student.age >= 20
GROUP BY department.dept_name
HAVING COUNT(student.id) > 1;
```

오늘 복습하면서 **학과명이 다른 테이블에 있는 경우 JOIN이 필요하다**는 점을 다시 확인했다.


## **C 복습**

### **포인터 + 구조체**

```c
struct Student {
    int age;
};

struct Student s = {20};
struct Student *p = &s;

p->age += 5;

printf("%d", s.age);
```

`p`가 `s`를 가리키므로 `p->age`는 `s.age`와 연결된다.

→ 출력 결과: `25`

### **재귀**

```c
void func(int n) {
    if (n == 0)
        return;

    printf("%d ", n);
    func(n - 1);
    printf("%d ", n);
}
```

재귀 호출 전과 후의 실행 순서를 구분해야 한다.

```text
func(2)
→ 2 출력
→ func(1)
  → 1 출력
  → func(0)
  → 1 출력
→ 2 출력

결과: 2 1 1 2
```


# **오늘 복습한 내용**

```text
SQL
→ WHERE / GROUP BY / HAVING / ORDER BY
→ JOIN

C
→ 포인터와 구조체
→ 구조체 포인터
→ 재귀 함수
```

복습 과정에서 배운 내용을 직접 문제로 다시 풀어보면서 SQL의 쿼리 흐름과 C 코드의 실행 순서를 확인했다.
