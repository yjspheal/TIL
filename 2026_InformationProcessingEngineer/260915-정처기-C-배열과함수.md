# **배열과 함수**

배열을 함수의 인자로 전달할 수 있다.

```c
void change(int arr[]) {
    arr[0] = 100;
}

int main() {
    int arr[] = {10, 20, 30};

    change(arr);

    printf("%d %d %d", arr[0], arr[1], arr[2]);
}
```

결과:

```text
100 20 30
```

## **배열 매개변수**

함수의 매개변수에서 `int arr[]`는 사실상 `int *arr`와 같은 의미로 처리된다.

```c
void change(int arr[])
```

```c
void change(int *arr)
```

따라서 배열 전체가 복사되는 것이 아니라 **배열의 시작 주소가 전달된다.**

```text
change(arr)
→ arr[0]부터 접근

change(arr + 1)
→ arr[1]부터 접근

change(arr + 2)
→ arr[2]부터 접근
```

예:

```c
void change(int *p) {
    p[0] = 50;
}

int arr[] = {10, 20, 30};

change(arr + 1);
```

→ `p`가 `arr[1]`을 가리키므로 결과는:

```text
10 50 30
```

## **static**

`static` 지역 변수는 함수 호출이 끝나도 값이 유지된다.

일반 지역 변수:

```c
void func() {
    int n = 0;
    n++;
    printf("%d ", n);
}
```

여러 번 호출하면:

```text
1 1 1
```

`static`을 사용하면:

```c
void func() {
    static int n = 0;
    n++;
    printf("%d ", n);
}
```

결과:

```text
1 2 3
```

`static` 지역 변수는 최초 한 번만 초기화되고 이후에는 이전 값이 유지된다.

```c
int func(int x) {
    static int sum = 0;
    sum += x;
    return sum;
}
```

```text
func(1) → 1
func(2) → 3
func(3) → 6
```
