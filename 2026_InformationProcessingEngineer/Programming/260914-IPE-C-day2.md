# **문자열 함수**

C에서는 문자열을 `char` 배열로 저장한다.

```c
char str[] = "hello";
```

문자열의 끝에는 널 문자 `'\0'`이 들어간다.

```text
h e l l o \0
```


## **strlen**

문자열의 길이를 반환한다.

```c
strlen("hello");
```

→ `5`

`'\0'`은 문자열 길이에 포함하지 않는다.


## **strcpy**

문자열을 복사한다.

```c
strcpy(목적지, 원본);
```

```c
char a[10] = "hello";
char b[10];

strcpy(b, a);
```

→ `a`의 문자열을 `b`에 복사


## **strcmp**

두 문자열을 비교한다.

```c
strcmp(a, b);
```

반환값:

```text
0      → 두 문자열이 같음
음수   → 첫 번째 문자열이 앞
양수   → 첫 번째 문자열이 뒤
```

예:

```c
strcmp("abc", "abd");
```

→ 음수

```c
strcmp("abc", "abc");
```

→ `0`


## **strcat**

문자열을 뒤에 연결한다.

```c
strcat(a, b);
```

→ `a` 뒤에 `b`를 붙인다.

```c
char a[20] = "hello";
char b[] = " world";

strcat(a, b);
```

→ `"hello world"`


# **포인터 연산**

## **포인터와 배열**

```c
int arr[] = {10, 20, 30};
int *p = arr;
```

`p`는 `arr[0]`을 가리킨다.

```text
*p       → arr[0]
*(p + 1) → arr[1]
*(p + 2) → arr[2]
```

```c
*(p + 1) = 50;
```

은 다음과 같은 효과를 가진다.

```c
arr[1] = 50;
```


## **증감 연산과 포인터**

포인터 자체를 증가시키는 것과 포인터가 가리키는 값을 증가시키는 것은 다르다.

```text
*p
→ 현재 가리키는 값

++p
→ 포인터를 다음 위치로 이동

(*p)++
→ 현재 가리키는 값을 1 증가
```

`*p++`는 다음과 같이 해석한다.

```c
*(p++)
```

→ 현재 값을 사용한 후 포인터를 다음 위치로 이동

반면:

```c
(*p)++
```

→ 현재 가리키는 값을 사용한 후 그 값을 증가


## **p[n]과 포인터 연산**

포인터에서는 다음 두 표현이 같은 의미이다.

```c
p[n]
```

```c
*(p + n)
```

따라서:

```c
p[-1]
```

도 문법적으로 사용할 수 있으며,

```c
*(p - 1)
```

과 같은 의미이다.

단, 배열의 범위를 벗어난 접근은 허용되지 않는다.


# **구조체, union, enum**

## **구조체 포인터**

구조체 변수는 `.`을 사용하고 구조체 포인터는 `->`를 사용한다.

```c
struct Student {
    int age;
};

struct Student s = {20};
struct Student *p = &s;
```

```c
s.age
```

→ 구조체 변수의 멤버 접근

```c
p->age
```

→ 구조체 포인터가 가리키는 멤버 접근

```text
p->age
=
(*p).age
```


## **union**

`union`은 여러 멤버가 **같은 메모리 공간을 공유**한다.

```c
union Data {
    int a;
    int b;
};
```

구조체와 달리 멤버들이 각각 별도의 공간을 사용하는 것이 아니다.

```text
struct
→ 멤버별로 별도 공간

union
→ 하나의 메모리 공간을 공유
```

따라서 같은 union의 다른 멤버에 값을 저장하면 기존 값이 영향을 받을 수 있다.


## **enum**

`enum`은 이름을 가진 정수 상수를 묶어 새로운 열거형을 정의할 때 사용한다.

```c
enum Week {
    MON,
    TUE,
    WED
};
```

값을 지정하지 않으면 기본적으로 0부터 시작한다.

```text
MON = 0
TUE = 1
WED = 2
```

enum 타입의 변수도 선언할 수 있다.

```c
enum Week day = TUE;
```

여기서 `enum Week`가 자료형 역할을 하고 `day`가 변수이다.

값을 직접 지정하면 다음 값은 이전 값에서 1 증가한다.

```c
enum Color {
    RED = 1,
    GREEN,
    BLUE = 5,
    YELLOW
};
```

```text
RED = 1
GREEN = 2
BLUE = 5
YELLOW = 6
```


# **실수한 부분**

## **strcmp 반환값**

`strcmp()`는 문자열 길이를 반환하는 함수가 아니다.

```c
strcmp("hello", "hello");
```

→ `0`

문자열을 비교한 결과를 반환한다.

```text
0      → 같음
음수   → 첫 번째 문자열이 앞
양수   → 첫 번째 문자열이 뒤
```


## **문자열의 음수 인덱스**

Python의 음수 인덱스와 C의 포인터 연산은 의미가 다르다.

Python:

```python
list[-1]
```

→ 마지막 원소

C:

```c
p[-1]
```

→ `*(p - 1)`

즉 현재 포인터 위치에서 한 칸 앞의 값을 의미한다.

```text
p[0]  = *p
p[1]  = *(p + 1)
p[-1] = *(p - 1)
```

```text
문자열
→ strlen / strcpy / strcmp / strcat

포인터
→ *p / ++p / (*p)++ / *p++

배열과 포인터
→ p[n] = *(p + n)

구조체
→ . / ->

union
→ 멤버가 같은 메모리 공간 공유

```
