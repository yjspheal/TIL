# C 기초 문법

## 포인터 복습

### &와 *

포인터는 다른 변수의 메모리 주소를 저장하는 변수이다.

```c
int a = 10;
int *p = &a;
```

```text
&a → a의 주소
p  → a의 주소를 저장
*p → p가 가리키는 주소의 값
```

따라서 다음 코드는 `a`의 값을 20으로 변경한다.

```c
*p = 20;
```

### 포인터와 배열

배열의 첫 번째 원소를 가리키는 포인터를 사용할 수 있다.

```c
int arr[] = {10, 20, 30};
int *p = arr;
```

```text
*p       → arr[0]
*(p + 1) → arr[1]
*(p + 2) → arr[2]
```

따라서 다음 두 코드는 같은 효과를 가진다.

```c
*(p + 1) = 50;
```

```c
arr[1] = 50;
```

## 구조체

`struct`를 사용하여 여러 데이터를 하나의 자료형으로 묶을 수 있다.

```c
struct Student {
    int age;
};

struct Student s = {20};
```

구조체 변수의 멤버는 `.`을 사용하여 접근한다.

```c
s.age
```

→ `20`

### 구조체 포인터

구조체를 가리키는 포인터에서는 `->`를 사용한다.

```c
struct Student s = {20};
struct Student *p = &s;

p->age = 30;
```

`p->age`는 다음과 같은 의미이다.

```c
(*p).age
```

정리:

```text
구조체 변수   → .
s.age

구조체 포인터 → ->
p->age
```

## 함수와 포인터

함수에 변수의 주소를 전달하면 함수 내부에서 원래 변수의 값을 변경할 수 있다.

```c
void change(int *x) {
    *x += 10;
}

int main() {
    int a = 5;
    change(&a);
}
```

`change(&a)`에서 `a`의 주소를 전달하므로 함수 안의 `*x`는 `a`를 가리킨다.

따라서 결과적으로 `a`는 `15`가 된다.

## 증감 연산자

전위와 후위 증감 연산자의 실행 순서를 구분해야 한다.

```text
++a → 먼저 증가한 후 사용
a++ → 먼저 사용한 후 증가
```

예:

```c
int a = 10;
int b = a++;
```

실행 후:

```text
a = 11
b = 10
```

반대로:

```c
int a = 5;
int b = ++a;
```

실행 후:

```text
a = 6
b = 6
```

## 비트 연산

비트 단위로 연산할 때 사용한다.

```text
& → AND
| → OR
^ → XOR
```

예:

```text
5 = 101
3 = 011

5 & 3
  101
& 011
-----
  001

→ 1
```

기본적으로:

```text
AND → 둘 다 1일 때 1
OR  → 하나라도 1이면 1
XOR → 서로 다를 때 1
```

## 재귀 함수

함수가 자기 자신을 다시 호출하는 것을 재귀라고 한다.

```c
int sum(int n) {
    if (n == 0)
        return 0;

    return n + sum(n - 1);
}
```

재귀 문제를 풀 때는 다음을 확인한다.

```text
① 종료 조건 확인
② 재귀 호출이 어디까지 내려가는지 확인
③ 호출 전과 후의 실행 순서 확인
```

다음 함수는 재귀 호출 전과 후의 출력 순서를 보여 준다.

```c
#include <stdio.h>

void print_numbers(int n) {
    if (n == 0)
        return;

    printf("%d ", n);
    print_numbers(n - 1);
    printf("%d ", n);
}
```

`print_numbers(3)`의 출력 결과는 다음과 같다.

```text
3 2 1 1 2 3
```

호출 전의 `printf`는 `3 2 1` 순서로, 호출 후의 `printf`는 `1 2 3` 순서로 실행된다.

# 오늘 배운 내용

```text
포인터
→ & / *

배열과 포인터
→ *(p + 1)

구조체
→ .

구조체 포인터
→ ->

함수 + 포인터
→ 주소를 전달하여 원본 값 변경

증감 연산자
→ ++a / a++

비트 연산
→ & / | / ^

재귀
→ 종료 조건 + 호출 순서 확인
```

C 코드 결과 문제를 풀 때는 코드를 한 번에 해석하기보다 변수의 현재 값과 실행 순서를 한 단계씩 추적하는 것이 중요하다.
